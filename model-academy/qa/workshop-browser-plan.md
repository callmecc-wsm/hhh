# 四条学习路线的浏览器验收

目标：证明教学环节能够走通、结果有证据、学习记录能够恢复，而非只检查首页外观。

执行：开发服务器启动后运行 `python qa/workshop-browser.py --url http://127.0.0.1:5173`。默认使用 `/usr/bin/chromium`，无头运行。截图和 JSON 结果位于 `qa/screenshots` 与 `qa/browser-results.json`。脚本使用隔离浏览器上下文，不修改使用者已有记录。

| 范围 | 核验内容 | 通过条件 |
| --- | --- | --- |
| 学习入口 | 预训练、微调、蒸馏、Harness | 四条路线可进入，返回总目录后可重新进入 |
| 原课程回归 | 原 12 章与首章实验 | 章节可导航；原理、自测、实验仍可打开 |
| 三门新增课程 | 各 12 章 | 标题与实验对应；没有空白页和渲染异常 |
| 数值实验 | 修改设置、预测、运行、观察、对照 | 新设置真实产生独立记录；切换旧记录显示原结果；修改条件时标明结果已过期 |
| 学习闭环 | 原理 6 节、自测、案例、独立解释 | 可提交、收到解释、修订答案；字数与自评门槛生效；自评不冒充自动认证 |
| 持久化 | 刷新与切换路线 | 当前章、实验记录、预测、观察、解释恢复，课程间互不覆盖 |
| 导出 | 学习记录与实验 JSON | 生成非空文件；包含实际输入的内容；JSON 可解析 |
| Harness | 审批暂停、拒绝、同意、继续、回归 | 外部写入在同意前未执行；拒绝不产生副作用；同意后能够继续；回归可以发现失效场景 |
| 故障恢复 | 非 JSON、错误 schema、残缺图表记录 | 显示恢复提示或安全回到初始记录，没有白屏 |
| 响应式 | 360×800 和桌面 1440×1000 | 文档无横向溢出；表格允许局部滚动；主要按钮可见可点击 |
| 键盘 | Tab、Enter、表单标签 | 可见焦点可以到达入口、章节、页签、控件与执行按钮 |
| 运行错误 | pageerror 和 error console | 没有未捕获渲染异常；问题记录原始错误与发生场景 |

测试报告明确区分自动测试、人工视觉检查和未能执行的项目；检查失败时保存截图，不将未执行项目写成通过。
