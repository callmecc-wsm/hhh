# 论文训练场 · Paper Lab

一个原生 HTML/CSS/JavaScript 的交互阅读训练场，不依赖后端或模型 API。

## 本地运行

```sh
python -m http.server 4173 --directory dist
```

打开 http://localhost:4173 。也可直接打开 `dist/index.html`；推荐 HTTP 服务，以获得一致的 localStorage 行为。

## 学习流程

9 篇论文，每篇有历史场景、预测、原文短摘录与批注、方法图解、原始数据节选、实验审查、个人判断与复盘。原始 PDF 在阅读阶段通过原文窗口访问，浏览器不支持嵌入时可在新窗口打开。

- 预测需要先选择起点并写理由，才解锁原文教学。
- 27 个短摘录逐段主动标注，选出句子的作用后才显示批注；保留原文上下文链接。
- 实验区包含表格、按表重绘的图、消融/条件审查和独立的统计模拟。
- 原句与表格行可存入证据夹，保留版本、页码与数值，按需引用到自己的判断。
- 两行比较区分百分点、相对百分比与 BLEU；分差不会自动被解释为因果贡献。
- 统计练习包含 Wilson 区间和同题配对的精确 McNemar 检验；InstructGPT 图重绘真实报告的置信区间。
- 每篇有一个新的虚构实验情境，记录首次选择、理由、把握与核对后的修正。
- 首次预测独立保存，之后修改预测也不会覆盖初始记录。旧版学习进度与笔记兼容。
- 结论、证据与限制先独立填写，才展示参考边界。
- 陌生论文迁移挑战分三步；链接用于记录，不自动解析。
- 预测、笔记、进度、自查保存在当前浏览器，可导出 Markdown；不跨设备同步。
- 不提供模型评分，不把最短字数或自评勾选解释为理解程度。

## 证据与范围

`dist/data.js` 是课程数据源。数据核对日期：2026-10-06。全文 PDF 下载与文本提取保存在未发布的 `research/` 目录供本地审计。网站只发布短摘录、带出处的表格节选和原创教学文字。

保留了原文不一致：Transformer EN–FR 正文与 Table 2 不一致，课程采用表格 41.8；Chinchilla 摘要 67.5 与 Table 6 的 67.6 不一致，课程采用后者。两处均在界面注明。

所有柱状图按原表重绘，未伪造误差条。Scaling Laws 的公式曲线与 Wilson 区间是明确标注的教学模拟，不是作者原始实验数据。统计模拟采用整数成功次数，假设独立同分布二项试验，不用于推导原论文显著性。

“后来”仅记录所链接来源支持的修正或适用边界，不是截至 2026 年的穷尽性文献综述。R1 固定 v1，以免将后续版本表格与历史主张混用。

## 维护与验证

- 原始课程：`dist/data.js`
- 主动阅读、新情境与术语：`dist/learning.js`
- 交互与存储：`dist/app.js`
- 样式：`dist/style.css`
- 网站配置：`.openai/hosting.json`
- 浏览器 QA：`qa/check.cjs`（需要 Playwright 与 Chromium，路径按本环境配置）

验收覆盖预测解锁、原文窗口、批注、错误反馈、全部 9 篇实验页、结论揭示、刷新后进度、手记下载、手机导航与横向溢出。后续内容更新须重新核对出处与版本。`qa/source-audit.cjs` 将 27 段摘录与下载 PDF 的指定页匹配；需要本地 `research/` 材料。新情境为明确标注的教学虚构实验，不冒充真实论文数据。
