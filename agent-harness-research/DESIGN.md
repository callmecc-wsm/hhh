# 研究工作台设计

主任务：让读者跟随一次可复现运行，再按自己的问题逐层追到源码。

色彩：纸面蓝 #edf3f8、正文深蓝 #182c43、动作蓝 #195fc4、工具青 #087e81、失败红 #ae3548、证据黄 #ad7417。

字体：中文使用系统无衬线字体，源码与身份用系统等宽；字号 14 / 16 / 21 / 32。长正文控制行长。

布局：顶部页签 → 左侧流程／选择器 → 中部因果过程 → 右侧 Inspector；移动端按相同阅读顺序折叠。序号只表达实际步骤。

视觉重点：真实 trace 的可点击时序图。其余区域保持安静，不以装饰性指标、模板卡片或持续动画占据注意力。

内容控制：默认只展示一条 trace、一个事件或一个机制；对照只显示两家；源码与原始 JSON 按需展开。实测、源码、官方和推断持续可见。

第二轮审视：取消百科式首页和七列大表，避免一打开就倾倒研究量。把“完成状态相同，验收结果不同”放进可切换的实验路径中。
